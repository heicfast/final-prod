# INTERIM-ASSETS

Assets shipped in v0.1.0 that are placeholders pending the v2 original set,
per the interim-asset policy.

| Asset                               | v1 (current)                                                                             | v2 plan                                                                                                                             |
| ----------------------------------- | ---------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| UI action icons                     | Lucide 1.61 (open-source, ISC) tinted via tokens                                         | Purpose-drawn two-tone set matching the corpus icon grammar (outline+fill, rounded joins, 2 px stroke at 24) on the same 24/48 grid |
| Filetype icons                      | Lucide category glyphs + per-category tint                                               | Two-tone filetype SVG family (105+ types) with type-tinted accents; RAW camera formats get dedicated silhouettes                    |
| App icon / NSIS banner              | Programmatically generated (PIL) original artwork — gradient tile + folder/restore glyph | Refined original artwork; same generator, pass 2 with optical corrections at 16/24/32                                               |
| Preview "page bitmaps" / thumbnails | Deterministic SVG generated by the mock connector                                        | Superseded entirely by real engine payloads (ADR-003)                                                                               |

**Not interim**: all UI strings (original, en + zh-CN), the token system,
the illustration-free empty states (icon + copy, no borrowed art), and the
icon's NSIS header BMP. Nothing in the repo is copied from the reference
product or any third-party asset library beyond the declared Lucide/ISC
usage.
