## 3. `scan` — the full flag surface (parse loop :1439-1609)

**Target (exactly one required**, :1610-1614): `--disk N` (PhysicalDriveN;
elevated) :1441-1446 · `--volume C:` (first char = letter; maps to the owning
disk extent, partition-slice view; BitLocker probed/unlocked first) :1447-1454
· `--image file` (VMDK/VHD/VHDX/flat `.img/.dmg/.raw`; `.edisk` refused
`ERR_UNSUPPORTED`; container magic verified — bad magic is an error, never a
silent flat fallback, engine/include/cr/storage/cr_image.h:20-29,75-80,100-101;
open+classify prints `[image] <path> (<fmt>, <layout>, <size>)` :489-529) —
**image targets need NO elevation** :551-559, :1305-1309.

Stage flags (defaults: quick+deep+carve ALL ON, `ScanConfig` cr_scan.h:203-205):
- `--quick-only` → disables deep AND carve (:1505-1509).
- `--no-carve` → disables carve only (:1510-1513). Deep stage CANNOT be
  disabled separately except via `--quick-only`.
- `--whole-disk` → lost-partition discovery over the whole disk incl.
  **unallocated space** (S-051: a plain `--disk N` scan already scans every
  in-table volume; this adds the lost sweep, :1482-1494).
- `--deep` → **deprecated alias for `--whole-disk`** (prints a note; NOT a deep-stage
  switch — the deep stage is always on) :1495-1504.
- No `quick`/`deep`/`carve` mode *names* exist — mode control is only these flags.

Output/session flags: `--out file.crsf` (save + stage-boundary auto-checkpoints;
atomic tmp+rename sink A-013, :1529-1530, :1057-1103, :1764-1779) ·
`--resume file.crsf` (resume; without `--out` updates the resumed file in place;
revalidation + boot-hash identity warning, :1550-1551, :1791-1854) ·
`--autosave-dir D` (completion auto-save `auto_<vol>_<ts>.crsf` + `last_scan.info`;
never fires when `--out/--resume` given; deletes the previous auto session
(M-154 retention), :1531-1540, :1994-2050, :2169) · `--label s` (label override;
precedence --label > engine-decoded > image stem, :1541-1549, :437-483) ·
`--log file` (detail run-log, [I]/[W]/[E] lines, :1552-1553, :278-301) ·
`--threads N` (0 = auto hw−1 clamp 1..8, :1514-1517; cr_scan.h:209).

Display flags: `--json` (one-line summary, §11) :1585-1588 · `--csv` (tree rows)
:1581-1584 · `--filter s` (ASCII-case-insensitive UTF-8 substring) :1573-1576 ·
`--deleted-only` :1577-1580 · `--pause-stdin` (keyboard pause 'p'/SPACE, resume
'r'/Enter; no-op when stdin redirected) :1558-1562, :235-266, :1861-1870.

Filter flags: `--filter-folder DIR` (repeatable, scan-time path-prefix filter,
volume-root relative, pruned at stage boundaries) :1518-1528. **No size/date/type
filters exist on the CLI** (category/size/date exist only in the cr_ui query ABI,
CORE-API.md:52).

Pre-scan passes: `--repair` (dry-run analyze+report) / `--repair-apply`
(consented execute; mounted volumes locked+letters removed during repair) /
`--repair-undo file` (default `rrecov-scan-repair-diskN.undo`) :1589-1599,
:356-417, :1674-1698, :1909-1937 · `--check` (read-only damage audit, 0x1001..
taxonomy, never aborts) :1600-1606, :1940-1956.

BitLocker: `--bitlocker-fvek hex` (64 hex = AES-128-XTS / 128 hex = AES-256-XTS;
in-stack decrypt so engines see plaintext) :1317-1326, :587-613, :656-737 ·
`--bitlocker-dict [file]` (bare = shipped 228-entry table; file = og-format
dictionary, ≤256 KiB, comma-terminated ASCII lines; consent-only) :1327-1336,
:615-650 · `--user-signs file` (EUUserData JSON signature DB; invalid input
aborts; executable-adjacent `userdata-defaults.json` auto-loads when present)
:1337-1425.

Unknown option → "unknown scan option", exit 1 (:1607-1608).

## 4. `tree` / `archive-list` / `sessions`

- `tree --in f.crsf` — reload + print the tree (no disk access, no elevation).
  `--json` = G-12 frozen schema (§11); `--csv` grammar: `"path",size,origin,
  deleted,confidence,first-extent-offset` (:999-1004). Junk-filtered rows
  (NODE_FLAG_JUNK_FILTERED, M-018/M-071) never print (:983-988).
- `archive-list --in f.crsf (--disk N | --image f) --node ID [--json]` —
  browse-inside archive inventory; re-opens the data source (`--disk` needs
  elevation) :2233-2296; JSON `{"kind","format","truncated","entries":[{"name",
  "size","compressed","crc_present"}]}` :2324-2346.
- `sessions [--dir D] [--json]` — lists `*.crsf` (default dir `.` :1116);
  newest-first; unreadable files are per-row data, only enumeration failure
  exits 1 (:1143-1155); frozen JSON schema :1210-1249 (path/valid/error/
  fs_family/stage_done_mask/configured_mask/files_found/deleted_found/
  carved_found/bytes_scanned/elapsed_ms/save_unix/label).

## 6. `health --disk N` (:2761-2871)

No `--json`. Prints ATA SMART table + derived counters + grade (S-024 4-status),
NVMe health block, SSD seek-penalty heuristic, per-device TRIM (with the SSD
TRIM warning). Opens `\\.\PhysicalDriveN` **GENERIC_READ|GENERIC_WRITE** itself
(:2779-2782). **Caveat: `health` has NO `require_privilege()` pre-gate** —
unelevated open failure exits **1** with "administrator rights required" text
(:2783-2789), unlike the exit-4 verbs. Exit 3 when every health source is
unavailable (:2867-2870, FB-H04).

## 7. `fix` (:3798-4073)

`fix --disk N [--part P] [--apply] [--undo file] [--undo-apply file]` — RawFixer
analyze (dry-run default) / consented transactional execute; undo log default
`rrecov-fix-diskN.undo`. `--part P` = 1-based partition slice (rebased to
disk-absolute, A-002 :4014-4025). `fix --chkdsk C:` — volume-letter operation
(no --disk): launches Windows `chkdsk /f`, 15-min bound; **exit 3 = errors
remain** (needs dismount), exit 2 launch failure (:3843-3880). Requires
elevation (pre-gated, :3799-3805).

## 8. `apply` (lost-partition, :3409-3754)

`apply --disk N --session file.crsf [--candidate N] [--apply] [--undo file]
[--boot-fix old-lba] [--boot-fix-bcd path]` — `--session` and `--in` are aliases
(:3439). Dry-run default (plan print, exit 0); `--apply` = consent; in-flight
journal `<session>.inflight`; undo default `rrecov-apply-diskN.undo`
(:3647-3660). Candidates come only from a `--whole-disk` scan session
(:3508-3513). Requires elevation (:3410-3416).

## 9. `image` (create, :2894-3171)

`image --create --disk N --out file.img [--from-sector F --to-sector T]
[--rescue] [--reverse] [--chunk-size N[k|M]] [--skip-size N] [--retries N]`
(:2919-2981). **Flat raw only** — `--out` must end `.img`/`.raw` (refuses
otherwise, D-147) :3018-3025. Writes `<out>.sha256` sidecar :3154-3158;
cancel keeps `<out>.partial`, exit 3 (:3161-3166); failure exit 2 (:3167-3170).
Sector range = inclusive [from,to], ≤15 digits, both-or-neither (:2986-3017).
`--rescue` = ddrescue-style two-pass with `<out>.mapfile` (re-runnable;
composes with neither a sector range nor a sidecar) :3028-3127. Requires
elevation (pre-gated even though it only reads, :2894-2901).

## 16. Top caveats for e2e automation

1. **Elevation is asymmetric**: the 7 pre-gated verbs exit 4 unelevated, but
   `health` exits 1 and `unlock` exits 2 on failure (:2783-2789, :3787-3793) —
   a harness asserting "every raw-disk verb exits 4 unelevated" will red on
   `health`. Image-target scan/recover/archive-list bypass the gate entirely
   (:551-559) — safest CI lane is `--image` (needs no elevation).
2. **`--deep` is a trap**: it is a deprecated alias for `--whole-disk`
   (lost-partition discovery), NOT the deep scan switch (:1495-1504). Deep
   stage is always on; `--quick-only` is the only deep-disabler. A "quick vs
